# User stories

| User type (role) | Action and Expected Outcome |
| --- | --- |
| Internal ERP User (all users type)| As an Internal ERP User, I want to be able to configure subscription parameters, notification text and channels to receive notifications, so that I can get up-to-date information about changes in entities.|
| Manager/Dispatcher | 1. As a Manager/Dispatcher, I want to be able to configure subscription parameters, so that I can be notified when a case becomes High priority on both creation and update and can react before the SLA breaches. <br>  2. As a Manager/Dispatcher, I want to be able to configure subscription parameters, so that I can reassign quickly when status changes within the Case entity from any status to "Escalated". <br>  3. As a Manager/Dispatcher, I want to be able to configure subscription parameters, so that I can proactively monitor team workload and upcoming task deadlines.|
| Agent/Technician| 1. As an Agent/Technician, I want to be notified when a new Case is created and assigned to me, so that I can manage and balance my workload. <br> 2. As an Agent/Technician, I want to be able to configure subscription parameters, so that I can plan and prioritize my appointments based on their due dates.|
| Internal ERP Administrator | As an Administrator, I want to be able to manage all subscriptions and notification templates, so that notification rules, templates, and recipients remain accurate and up to date. |
